# ThreatCaddy 2.0.1 (not released)

2.0.1 was deployed to threatcaddy.com and published as the GHCR `latest`
server image (`sha256:d97ee2c09f501bd40184379809dd21cde1c7ff80b8e11e9a6a2caf242678f03d`,
source `8020e82d`) on 15 November 2026, but no 2.0.1 downloads or tag were
released. An independent review then found regressions in that build, including
evidence imports that rejected ordinary PDFs and spreadsheets, sample removal
that deleted user content without asking, and a server runtime behind a Node.js
security release.

All 2.0.1 changes, with those regressions fixed, are released as
[ThreatCaddy 2.0.2](v2.0.2.md). Servers running an image labelled 2.0.1 should
upgrade to the 2.0.2 image digest in that release's manifest.
